---

The ARES API is a JSON REST API served at `/api/` and generated by Django REST Framework's `DefaultRouter`. All request and response bodies use `application/json`. Each of the three resource collections — robots, sensores, and lecturas — is registered on the router and supports the full set of CRUD operations out of the box.

## Base URL

For local development, the API is available at:

```
http://localhost:8000/api/
```

## HTTP methods

Each resource supports the full set of CRUD operations through DRF's `ModelViewSet`. The table below shows the mapping between HTTP methods and actions for any `{resource}` prefix.

| Method | Path | Action |
|---|---|---|
| `GET` | `/api/{resource}/` | List all records |
| `POST` | `/api/{resource}/` | Create a new record |
| `GET` | `/api/{resource}/{id}/` | Retrieve one record |
| `PUT` | `/api/{resource}/{id}/` | Full update |
| `PATCH` | `/api/{resource}/{id}/` | Partial update |
| `DELETE` | `/api/{resource}/{id}/` | Delete |

## Response format

Responses are JSON arrays for list endpoints and JSON objects for detail endpoints. The example below shows a list response from `GET /api/robots/`:

```json
[
  {
    "id": 1,
    "nombre": "ARES-01",
    "estado": "activo",
    "latitud": 19.4326,
    "longitud": -99.1332,
    "fecha_registro": "2024-01-15T10:30:00Z"
  }
]
```

## Browsable API

DRF ships with a browsable API interface. Open `http://localhost:8000/api/` in a browser to explore all registered endpoints, inspect responses, and submit test requests without any additional tooling.

<Note>
  POST, PUT, and PATCH requests must include the `Content-Type: application/json` header, and the request body must be valid JSON. Requests without this header will be rejected with a `415 Unsupported Media Type` error.
</Note>
