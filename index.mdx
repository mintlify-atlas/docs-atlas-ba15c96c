Proyecto ARES provides a REST API backend for managing autonomous rescue robots in the field. It lets you register robots with location data, attach sensors to them, and continuously ingest sensor readings — all through a straightforward HTTP API built with Django REST Framework.

## How ARES works

ARES models the lifecycle of a rescue operation through three core resources:

<Steps>
  <Step title="Register robots">
    Add rescue robots to the system with their name, operational status, and GPS coordinates. Each robot is tracked independently.
  </Step>
  <Step title="Attach sensors">
    Link sensors to robots by specifying the sensor type (e.g., temperature, gas) and its measurement unit. A robot can have multiple sensors.
  </Step>
  <Step title="Ingest readings">
    Submit sensor readings as they arrive from the field. Each reading records the measured value, timestamp, and whether it has been processed.
  </Step>
</Steps>
