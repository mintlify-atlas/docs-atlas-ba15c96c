---
title: "Quickstart: set up ARES and make your first API call"
description: "Set up Proyecto ARES locally and make your first three API calls — register a robot, attach a sensor, and submit a reading — in under five minutes."
---

This guide walks you through running the ARES backend locally and making your first three API calls: registering a robot, attaching a sensor to it, and submitting a sensor reading.

<Steps>
  <Step title="Clone the repository and install dependencies">
    Clone the ARES repository and install the required Python packages:

    ```bash
    git clone https://github.com/rootKarka/Proyeecto-ARES.git
    cd Proyeecto-ARES
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Run migrations">
    Apply the database migrations to create the tables for robots, sensors, and readings:

    ```bash
    python manage.py migrate
    ```
  </Step>
  <Step title="Start the development server">
    Start the Django development server:

    ```bash
    python manage.py runserver
    ```

    The API will be available at `http://localhost:8000/api/`.
  </Step>
  <Step title="Register your first robot">
    Send a `POST` request to create a robot with a name, status, and GPS coordinates:

    ```bash
    curl -X POST http://localhost:8000/api/robots/ \
      -H "Content-Type: application/json" \
      -d '{"nombre": "ARES-01", "estado": "activo", "latitud": 19.4326, "longitud": -99.1332}'
    ```

    A successful response returns the new robot object with its assigned `id`.

    ```json
    {
      "id": 1,
      "nombre": "ARES-01",
      "estado": "activo",
      "latitud": 19.4326,
      "longitud": -99.1332,
      "fecha_registro": "2026-04-13T00:00:00Z"
    }
    ```
  </Step>
  <Step title="Attach a sensor">
    Link a sensor to the robot you just created using its `id`:

    ```bash
    curl -X POST http://localhost:8000/api/sensores/ \
      -H "Content-Type: application/json" \
      -d '{"tipo": "temperatura", "unidad": "°C", "robot": 1}'
    ```

    ```json
    {
      "id": 1,
      "tipo": "temperatura",
      "unidad": "°C",
      "robot": 1
    }
    ```
  </Step>
  <Step title="Submit a reading">
    Submit a sensor reading from the field using the sensor's `id`:

    ```bash
    curl -X POST http://localhost:8000/api/lecturas/ \
      -H "Content-Type: application/json" \
      -d '{"valor": 36.5, "estado_procesamiento": false, "sensor": 1}'
    ```

    ```json
    {
      "id": 1,
      "valor": 36.5,
      "fecha": "2026-04-13T00:00:00Z",
      "estado_procesamiento": false,
      "sensor": 1
    }
    ```
  </Step>
</Steps>

<Tip>
  You can explore and test all endpoints interactively through the browsable API at [http://localhost:8000/api/](http://localhost:8000/api/). No extra tooling required — just open it in your browser while the development server is running.
</Tip>
